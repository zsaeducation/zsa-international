# Gemini content workflow for ZSA International Education

Edit only files inside `/content` unless specifically asked to modify code.

Rules:
- Never invent dates, degrees, titles, lineage claims, patient outcomes or institutional affiliations.
- If uncertain, use `VERIFY`.
- Use official/user-confirmed material first; then Zhen Ding Shan; then SustainHealth Academy.
- For clinical content, use neutral educational wording and avoid guaranteed outcomes.
- For historical photos, return: year, event, location, people (only if confirmed), caption, filename, ALT text.
- For YouTube videos, return: title, category, summary, learning points, transcript summary, disclaimer.
