- Separate direct lineage under Professor Ming Qing Zhu
- Traditional Chinese Medicine + Western Medicine

- Dedicated Harmonizing Form and Spirit page

- /en/ architecture plus expandable language selector

## Important photo note
The supplied historical images are represented by clearly labelled placement blocks in this package. This prevents accidental use of the wrong person/date/clinical image. Replace these blocks with the approved original image files when they are available in the project repository.
